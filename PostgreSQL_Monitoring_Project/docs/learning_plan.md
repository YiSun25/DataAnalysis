# Learning Plan

## Stage 1: SQL Fundamentals
Focus:
- CREATE TABLE
- INSERT
- SELECT
- WHERE
- ORDER BY
- UPDATE
- DELETE

Goal:
- Be comfortable with basic table operations in PostgreSQL

## Stage 2: Aggregation
Focus:
- COUNT
- AVG
- MAX
- MIN
- SUM
- GROUP BY
- HAVING

Goal:
- Be able to perform basic analytical queries

## Stage 3: Multi-table Queries
Focus:
- PRIMARY KEY
- FOREIGN KEY
- INNER JOIN
- LEFT JOIN

Goal:
- Understand relational database structure and join logic

## Stage 4: Advanced SQL
Focus:
- CASE WHEN
- Window functions
- ROW_NUMBER
- RANK
- DENSE_RANK
- LAG / LEAD

Goal:
- Solve more realistic data analysis problems

## Stage 5: Monitoring Project Schema
Focus:
- Create raw sensor data table
- Create aggregated statistics table

Goal:
- Build the database foundation for the project

## Stage 6: Python + PostgreSQL
Focus:
- Python database connection
- Insert and query data with Python
- Simulate sensor data automatically

Goal:
- Build a simple automated data pipeline

## Stage 7: Visualization
Focus:
- Grafana for real-time monitoring
- Power BI for historical reporting

Goal:
- Show both monitoring capability and data analysis capability
